# Custom Paper Theme

The visual shell comes from a local theme module. The compiled note stays
self-contained and uses the neutral `__htmlKitArtifact` protocol name when an
interactive artifact needs runtime data.

## Theme boundary

The core owns the document contract, verification, and offline guarantees.
The theme owns only its styles and body shell.
